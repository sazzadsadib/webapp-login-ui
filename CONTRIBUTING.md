# Contributing

1. Open an issue before a large behavioral or public-API change.
2. Do not include credentials, production user data, or service-role keys in issues, tests, or commits.
3. Run `npm test`, `npm run build:demo`, and `npm pack --dry-run` before opening a pull request.
4. Add regression tests for every bug or security fix.
5. Keep security claims limited to behavior the repository actually implements and tests.

Report vulnerabilities privately using the process in `SECURITY.md`.
